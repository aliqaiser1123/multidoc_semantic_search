# 🔎 Semantic Search Engine

A Multi-Document Semantic Search Engine built using **Sentence Transformers**, **ChromaDB**, and **Streamlit**. Instead of relying on exact keyword matching, it retrieves documents based on their semantic meaning using vector embeddings.

## ✨ Features

- 📄 Multi-document (.txt) upload
- 🧠 Semantic search using Sentence Transformers
- 📦 ChromaDB vector database
- 🏷️ Metadata-based document filtering
- 🎯 Top-K document retrieval
- ⚡ Fast and interactive Streamlit interface

## 🛠️ Tech Stack

- Python
- Streamlit
- Sentence Transformers
- ChromaDB
- all-MiniLM-L6-v2

## 🚀 Future Improvements

- PDF and DOCX support
- Retrieval-Augmented Generation (RAG)
- Hybrid Search (Keyword + Semantic)
